# CMS adapter guide

An adapter connects Inka to your content store through one contract, so editors get the same experience whatever sits behind it. This guide will cover writing an adapter for a store Inka does not support yet, and serving different sections of a site from different stores.

*This guide is upcoming — start from the Plone adapter and the [How Inka works](../architecture.md) architecture.*
