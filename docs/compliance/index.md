# Compliance & audit

Some rules a machine can settle as a page is written — colour contrast, heading order, whether a block is on-system. Others need a person. This guide will cover the plugin points for putting those checks in front of editors, and the record they leave: what was checked, who signed it off, and on what basis.

*This guide is upcoming — the conformance and audit plugins are on the roadmap.*
